# Free and Pro

This repo is the **free, open** version. The core curriculum (Basic to Expert), the AI agent skills, the basic templates, and the basic scripts will stay free here.

A paid **Pro** version is being planned. It is **not available yet**, and there is no price or release date. This page only explains the boundary between the two so it is clear what you get today.

## What stays free in this repo
- All modules in `01-basic` to `04-expert` (Indonesian) and `en/` (English).
- The skills `seo-playbook-id` and `seo-playbook` for AI agents.
- Basic templates, basic scripts, the glossary, and the verified claims list.
- Corrections for outdated or wrong claims.

## Direction of Pro (a plan, may change)
- Advanced templates: keyword map spreadsheets with formulas, report dashboards, more detailed technical audit checklists.
- Advanced AI agent skills for repeated workflows, for example audits from a Search Console export.
- Exercises with answer keys and grading rubrics.
- Summaries of Google documentation changes that affect the material, with check dates.

Pro content is stored separately and is not in this public repo.

## The same rules apply in Pro
No invented numbers, no fictional case studies, labeled and dated claims. No promises of results or income.
