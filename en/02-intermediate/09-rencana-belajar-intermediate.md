# 09. Intermediate Study Plan (6 weeks)

**Prerequisite:** pass the 01-basic criteria

- **Week 1:** modules 01 and 02. Result: a cluster map and a pillar-supporting page map.
- **Week 2:** module 03. Result: a technical audit of one site.
- **Week 3:** module 04. Result: an 8-article content calendar.
- **Week 4:** modules 05 and 06. Result: a NAP audit or a list of 10 link targets.
- **Week 5:** module 07. Result: a one-page monthly report.
- **Week 6:** module 08 and review. Result: a mini project.

## Mini project
Take one small site. Produce: a technical audit, a keyword map, 3 new or updated pieces of content, and a before and after report with GSC data. Write the results as they are, including what did not work.

## Completion criteria
- [ ] Can find and fix one cannibalization case with data
- [ ] Technical audit with pass or fail status per item
- [ ] Report contains one firm recommendation with a numeric reason

Continue to `03-advanced/`.
