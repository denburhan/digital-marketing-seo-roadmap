# Glosarium Singkat

Lihat definisi lebih lengkap di `01-basic/04-istilah-seo-dasar.md`.

- **AEO / GEO:** istilah komunitas untuk optimasi bagi mesin jawaban dan AI. Bukan terminologi resmi Google.
- **AI Overview / AI Mode:** fitur generative AI di Google Search.
- **Canonical:** URL utama dari sekelompok halaman mirip.
- **CTR:** klik dibagi impresi.
- **E-E-A-T:** Experience, Expertise, Authoritativeness, Trust.
- **GSC:** Google Search Console.
- **INP / LCP / CLS:** metrik Core Web Vitals.
- **Intent:** tujuan di balik query.
- **NAP:** Name, Address, Phone.
- **SERP:** halaman hasil pencarian.
- **TOFU / MOFU / BOFU:** tahap funnel.
- **YMYL:** topik yang bisa memengaruhi kesehatan, keuangan, atau keselamatan pembaca.
