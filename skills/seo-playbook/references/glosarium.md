# Short Glossary

See fuller definitions in `01-basic/04-istilah-seo-dasar.md`.

- **AEO / GEO:** community terms for optimizing for answer engines and AI. Not official Google terminology.
- **AI Overview / AI Mode:** generative AI features in Google Search.
- **Canonical:** the main URL of a group of similar pages.
- **CTR:** clicks divided by impressions.
- **E-E-A-T:** Experience, Expertise, Authoritativeness, Trust.
- **GSC:** Google Search Console.
- **INP / LCP / CLS:** Core Web Vitals metrics.
- **Intent:** the purpose behind a query.
- **NAP:** Name, Address, Phone.
- **SERP:** search engine results page.
- **TOFU / MOFU / BOFU:** funnel stages.
- **YMYL:** topics that can affect the reader's health, finances, or safety.
